# NovaAuth - Login System

A modern full-stack login application built with:

- **Frontend**: React + Vite + Tailwind CSS
- **Backend**: Node.js + Express

## Features

- Clean and responsive login UI
- Frontend form validation
- API integration with Axios
- Mock authentication
- Protected Dashboard page
- Error handling

## How to Run

### Backend
```bash
cd nova-auth-backend
node src/index.js
